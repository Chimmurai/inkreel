# Security

InkReel runs entirely on your computer and does not open network connections (the only socket is a local one used to hand a file to an
already running window). If you find a vulnerability, please do not open a public issue: write to raimex.crucible@gmail.com with the
version, what you found and how to reproduce it. You will get an answer as soon as possible.

Official downloads are only the [Microsoft Store page](https://apps.microsoft.com/detail/9NW62SPG91ZR), the
[GitHub releases](https://github.com/Chimmurai/inkreel/releases) (each lists the SHA-256 of the installer) and
https://inkreel.raimex.space. Copies from anywhere else are not ours.
